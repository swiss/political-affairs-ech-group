# Documents as a backup method

* In general the schemas of this ech fachgruppe promote to use publication of all data as models.
* Therefore it is suggested to not use documents to convey information and use this class a minimal as possible. Although it helps to guide the process to a data modeled world in a proper manner.
* The use of documents should be seen as a legacy system which is available for not yet structured parts.

## Modelling of the document structure (FRBR)

As used in other data models we propose to retake Functional Requirements for Bibliographic Records (FRBR), e.g. ELI (which is used for the law text in this fachgruppe).

The cascade of classes allows to properly attach and also extend later on different versions of documents in regard of language and format. 

We retake the Work, Expression and Manifestation (taken from Wikipedia):

Work is a "distinct intellectual or artistic creation."[3] For example, Beethoven's Ninth Symphony, regardless of who performed it, is a work.

Expression is "the specific intellectual or artistic form that a work takes each time it is 'realized.'"[3] An audiobook and a text edition of a book are different expressions of the same work. For music, this covers both writing down the sheet music as well as performing it. Each draft of the score is an expression. The professionally-recorded 1996 London Philharmonic performance of Beethoven's Ninth is another expression.

Manifestation is "the physical embodiment of an expression of a work. As an entity, manifestation represents all the physical objects that bear the same characteristics, in respect to both intellectual content and physical form."[3] The recordings of that 1996 performance released on vinyl are one manifestation. The same performance released on CD is another manifestation.
