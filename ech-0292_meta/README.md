# eCH-0292 Metaprozesse zu politischen Geschäften

Diese Subgruppe befasst sich mit Metaprozessen zu politischen Geschäften, wie bspw. dem Umgang mit Dokumenten gemäss FRBR Standard.

> [!IMPORTANT]
> Neben den analog der weiteren Subgruppen erarbeiteten Datenmodellen, werden in dieser Subgruppe auch die **Common Data Elements** (CDE) definiert. Dies sind Elemente, die in den Schemata der anderen Subgruppen wiederverwendet werden können. Die CDEs werden in einem vom regulären `schema.yaml` abweichenden Schema `schema_common.yaml` definiert. Dieses `schema_common.yaml` wird in den Schemata der anderen Subgruppen importiert und die CDEs können dort verwendet werden. Weil das Schema "vollständig" importiert wird (nicht nur Verweise), ist die automatisch erstellte Dokumentation der CDEs in den anderen Schemata ebenfalls verfügbar. Für das `schema_common.yaml` wird dementsprechend keine eigene Dokumentation erstellt, sondern die CDEs werden in der Dokumentation der anderen Schemata angezeigt.
