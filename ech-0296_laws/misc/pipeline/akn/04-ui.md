# 04-ui

Svelte + ProseMirror + CodeMirror frontend for the AKN-CH pipeline.

## Start

```bash
# Terminal 1 — FastAPI backend
cd akn-pipeline
PYTHONPATH=packages uvicorn api.main:app --reload --port 8787

# Terminal 2 — Svelte dev server (proxies /api → :8787)
cd akn-pipeline/ui
npm run dev
# → http://localhost:5173
```

## State management

All state lives in `src/stores.js`. Editors are imperative (ProseMirror, CodeMirror) — stores hold the *serialised* state only.

```
documentUrl         → writable  — URL bar input
resolvedRef         → writable  — /resolve API response
selectionRaw        → writable  — PM plugin writes compact string (#a47-p2)
selectionState      → writable  — /selection API response
currentDisplayUri   → derived   — resolvedRef + selectionState + uriMode
currentFragmentUri  → derived   — full AKN URI string
currentHumanCitation→ derived   — human citation in active lang
operations          → writable  — append-only backend op log
aknXmlSource        → writable  — CodeMirror ↔ PM bridge
citationLang        → writable  — de / fr / it
uriMode             → writable  — hash / slash / portion
```

### Reactive data flow

```
User pastes URL
  → Toolbar calls resolveUrl()
    → GET /resolve → resolvedRef.set(data)
      → aknXmlSource.set(skeleton XML)
        → CodeMirror updates
        → PM doc rebuilds (if full XML)

User clicks in PM / selects text
  → selectionPlugin.update()
    → posToCompact() → selectionRaw.set('#a47-p2')
      → resolveSelection() → POST /selection → selectionState.set(data)
        → currentDisplayUri recomputes → ReferenceBar updates
        → RightPanel annotation panel updates

User types in compact field (ReferenceBar)
  → resolveSelection() → selectionState.set(data)
    → currentDisplayUri recomputes

User clicks Link (LeftPanel toolbar)
  → PM transaction: addMark(ref, { href, compact, human })
  → logOp({ type: 'annotation', ... })

User clicks Export XML (LeftPanel toolbar)
  → Walks PM doc → builds AKN XML string
  → aknXmlSource.set(xml)
  → logOp({ type: 'xml-export', ... })
```

## Fragment types

| Type | Compact | Meaning |
|---|---|---|
| Single | `#a47-p2-lit-a` | Art. 47 Abs. 2 lit. a |
| Range | `#a7~a18` | Art. 7 – Art. 18 |
| Range with depth | `#a7_p2~a8_p2` | Art. 7 Abs. 2 – Art. 8 Abs. 2 |
| Multi | `#a7,a11,a28` | Art. 7; Art. 11; Art. 28 |

Range endpoints use `_` (not `-`) as level separator to avoid ambiguity.

## URI modes (ReferenceBar toggle)

| Mode | Example | Use |
|---|---|---|
| `#` hash | `bv#art_47.para_2` | Browser anchor, PM link href |
| `/` slash | `/akn/ch/lei/.../art_47/para_2` | REST GET resource, ELI subdivision |
| `~` portion | `/akn/.../expr~art_7->art_18` | AKN portion reference |
