## ELI core components

All optional, usable in any order (per the guide: "They are all optional, and can be used in any order, depending on how the law is cited"). Status here tracks whether legaldocml.ch has mapped/instantiated each one yet, not whether ELI itself requires it (it doesn't).

| Component | Recommended format | Status | Notes |
|---|---|---|---|
| `{jurisdiction}` | 2-letter country code | mapped | lib/uris/frbr_uri profiles use ch / ch-zh / ch-zg / ch-be-351 / ch-vd-5586 / ch-zh-261. |
| `{agent}` | none — member states define their own | gap | Not yet distinguished from `jurisdiction` in our profiles; may fold into jurisdiction for cantons. |
| `{subagent}` | none — member states define their own | gap | Finer administrative substructure than `agent`. |
| `{year}` | 4 digits | mapped | frbr_uri resolver templates use {date} as YYYY-MM-DD; {year} alone not separately exposed. |
| `{month}` | 2 digits | gap | Can be used without year/day per the guide; not separately exposed by frbr_uri today. |
| `{day}` | 2 digits | gap |  |
| `{type}` | none — member states define their own | mapped | frbr_uri profiles' document_types (act, ordinance, constitution, decision). |
| `{subtype}` | none — member states define their own | mapped | frbr_uri profiles' per-doc-type `subtype` (e.g. lei, verordnung, verfassung, entscheid). |
| `{natural_identifier}` | none — member states define their own | mapped | The {number} field in frbr_uri (SR number, LS number, AS/OS publication sequence, etc.). |
| `{domain}` | none — member states define their own | gap | Thematic classification. |
| `{level_1..level_N}` | none — see subdivisions section | mapped | This is lib/uris/frbr_uri/fragment.py's subdivision-code system (art_/para_/lit_/etc.). |
| `{point_in_time}` | YYYYMMDD or YYYY-MM-DD | mapped | frbr_uri's {version} / {version_date} fields, ISO 8601 (YYYY-MM-DD). |
| `{version}` | none — member states define their own | mapped | Distinguishes a base act from a consolidated version. |
| `{language}` | 3-letter language codes (ISO 639-1... sic, actually 639-2/T in practice) | mapped | frbr_uri profiles' language_codes map 2-letter (de/fr/it/rm) to 3-letter (deu/fra/ita/roh). |
| `{format}` | file format, e.g. pdf or html | mapped | frbr_uri resolver's {format} argument (xml/html/pdf). |

## ELI-DL (draft legislation) — status: gap

| Component | Remarks |
|---|---|
| `/eli/dl root` | MUST prefix all ELI-DL URIs, per BCP-14, to separate the draft corpus from published acts. |
| `process_type` | Nature of the legislative drafting process; a fixed value/code if the exact nature is unknown. |
| `process_identifier` | Identifier/number/reference of the legislative process. |
| `activity` | Reference to an activity in the course of a legislative process (type + sequence/date). |
| `subactivity` | Decomposition of a larger activity into smaller activities. |
| `document_type` | Nature of a document produced during the legislative process. |
